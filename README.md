# 抖音「人群挖掘」Skill · 学员使用说明

> 你是做抖音电商内容的。这个 Skill 帮你回答一个最头疼的问题：
> **这条视频，到底该拍给谁看？**

---

## 它能帮你做什么

给它一份"商品买点清单"，它会告诉你：

- 这个商品到底**卖给谁**（不是"18–35 岁女性"这种废话）
- 哪几类人最容易掏钱、**第一条视频先打谁**
- 对这群人，该用**哪句话术**打动、发视频打**什么话题标签**
- 这群人是不是真的在抖音上火（每条结论都挂着真实视频的点赞数，不是瞎编）

一句话：**商家脑子里只有"我的产品好在哪"，这个 Skill 帮你翻译成"谁会为它买单"。**

---

## 你需要准备什么

只需要一样东西：**上一步「卖点转买点」生成的买点清单**（一个 HTML 文件，或一段买点文字）。

- 如果你还没有买点清单 → 先跑上一步 Skill，把商品资料变成买点清单。
- 这个 Skill **只吃挑好的买点**，不直接吃原始商品图/详情页。

> 流程是固定的两步：第一步把"产品卖点"变成"购买理由"，第二步（就是这个 Skill）把"购买理由"变成"具体人群"。

---

## 三步上手

**第 1 步 · 安装**
把整个 `persona-mining` 文件夹，放进你豆包的 Skills 目录里。

**第 2 步 · 打开豆包，说一句话**
> "用一下人群挖掘这个 Skill，这是我的买点清单："
> 然后把你的买点清单文件/文字贴进去。

**第 3 步 · 等结果**
它会自动去抖音上核实这群人是不是真的存在，最后给你一个 HTML 文件——**人群匹配表**，用浏览器打开就能看。

---

## 你会拿到什么

一份"人群匹配表"，里面有 **3–4 张人群卡**。每张卡就四行，扫一眼就读完：

| 行 | 写的是 | 你拿去干嘛 |
|---|---|---|
| **这群人是谁** | 年龄区间 + 身份 + 平时爱刷什么内容 | 定这条视频拍给谁 |
| **他们怎么想** | 痛点 / 为什么买 / 怕什么 | 写脚本时知道戳哪、避哪 |
| **怎么打动他** | 用哪个买点、一句什么话术 | 直接抄成口播开头 |
| **怎么找到他** | 拍什么内容、打什么话题标签 | 发布时选标签、找对标 |

每张卡下面还有一行 **`✓ 已验证`**——那是抖音上真有这么一群人在看的证据（附真实视频标题和点赞数）。

最后每张卡会标一个结论：

- 🟢 **主攻**：第一波就拍这群人，别犹豫
- 🔵 **可测试**：有机会，但先小范围试
- ⚪ **叠加**：不用单独拍，内容里顺带提一下就行

> 为什么只给 3–4 张，不给十几张？因为**贪多等于没重点**——第一条视频只能服务好一群人，多了你拍不过来。

## 常见问题

**Q：为什么不是直接告诉我"卖给 18–35 岁女性"？**
A：那种话没法拍视频。这个 Skill 给的是"爱刷开学收纳 vlog、怕箱子半路炸开的住校生"——这种你看完就知道镜头该对着谁、开头第一句说什么。

**Q：输入要什么格式？**
A：买点清单的 HTML 文件最好；直接把买点文字复制粘贴进去也行。

**Q：怎么保证人群不是 AI 瞎编的？**
A：每张卡下面那行"✓ 已验证"就是证据——它在抖音上真的搜到了一群人在看的内容、还有点赞量。搜不到真实内容支撑的人群，它会自动降级或直接删掉，不会硬凑。

**Q：为什么同一个商品，不同品类挖出来的人完全不一样？**
A：因为它是**从这个商品自己的买点倒推**人群的，不是套一个固定模板。卖鞋就找"穿搭显高"的人，卖马桶粉就找"下班太懒"的人，卖包就找"想要第一只大牌包"的人。
