# S2 人群卡 Schema（S3/S4 共用）

人群卡字段定死，S3 场景卡、S4 组合器直接消费这套字段。人群从 S1 买点库倒推而来。

## 人群卡字段

| 字段 | 定义 | 示例（骆驼女鞋） | 示例（兔力泡泡粉） |
|---|---|---|---|
| persona_id | 人群编号 | P-01 | P-01 |
| persona_name | 一句话人群标签 | 小个子显高党 | 合租/租房尴尬党 |
| profile | 画像：年龄区间 / 身份 / 生活状态 / 兴趣爱好（区间即可，不编化名） | 18–35岁、150–160cm，爱刷小个子穿搭/矮子乐话题 | 20–30岁合租独居，爱刷租房好物/拼多多平价清单 |
| psychology | 购买心理：痛点强度 / 决策动机 / 顾虑（顾虑对应内容侧负面信号） | 显矮自卑→隐形增高；顾虑度数虚标 | 怕臭到室友→低成本不刷马桶；顾虑便宜货没用 |
| matched_bp | 匹配买点 ID（含 Tier） | BP-01(T1) / BP-02(T2) | BP-01(T1) / BP-02(T1) |
| pitch | 打动卖点：用哪个买点、什么表达角度（一句话） | "日常隐形增高5cm"，拍真人量身高反击虚标 | "倒一包就不管，第二天一冲不臭" |
| outreach | 触达方式：内容形态 + 话题标签 | 增高测评对比；#小个子穿搭 #矮子乐 | 租房好物合集；#租房好物 #卫生间除臭 |
| content_signal | 内容侧信号：该人群在抖音的真实活跃证据（一行，✓已验证） | 矮子乐合集 6.6k 赞 | 拼多多懒人好物 725 赞"租房党友好" |
| scores | 三维打分：卖点匹配度 / 付费意愿 / 人群规模（各 1-10） | 9 / 8 / 9 | 9 / 7 / 8 |
| priority | 结论：主攻 / 可测试 / 叠加 | 主攻 | 主攻 |

## 口径定义

**人群从哪来**
- 从 S1 买点库（Tier 1/2）倒推："谁最需要这个买点"。禁止先定宽泛区间再套卖点。
- 换品类后人群画像要跟着买点变：服饰鞋包常是"身份/穿搭驱动"，家居清洁常是"生活状态/痛点驱动"——不把上一个商品的人群标签平移。

**画像写法**
- 区间 + 身份 + 生活状态 + 兴趣爱好，一行写完。
- 兴趣爱好要具体到"刷什么内容、信什么、买同类看什么"。
- 禁止编造"璐璐/小鹿"这类具体化名人物。

**打分**
- 卖点匹配度：该人对买点的需求强度
- 付费意愿：这群人为这类东西掏钱的意愿（平价耗材偏低，耐用品/悦己品偏高），按品类自适应
- 人群规模：抖音上这群人的体量

**结论分档**
- 主攻：匹配高+规模大，第一波内容就打
- 可测试：需求真实但规模/付费待验证，第二波测
- 叠加：不单独主攻，内容里自然覆盖

**内容侧信号（防误读）**
- content_signal 必须有抖音真实内容支撑（标题+互动量），收敛成一行。
- 证据标注来源类型：本商品事实 vs 抖音同品类内容，不混读。
- 内容侧新发现人群（原买点没覆盖）→ 重点标注，是给商家的增量价值。

## 收敛要求

- 主攻卡一般 3-4 张（太多说明没做取舍）。
- 一个人被多个买点覆盖时合并成一张卡，matched_bp 列全。
